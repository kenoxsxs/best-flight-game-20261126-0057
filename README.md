Dusk Runner — a courier's race with the setting sun. You fly the Kestrel (callsign DUSK-1), a rugged high-wing courier plane, through a mountain archipelago at golden hour, delivering supplies to remote outposts before dark. The sun is the timer: the sky darkens as the clock runs out. Three genuinely different sorties (Race the Light, Last Call, Heavy Load), real fuel and damage that change how the aircraft flies, a dense neon HUD, a cockpit with three live MFD screens, and a smooth chase camera — all in real 3D (Three.js, vendored locally, no network).

## Run it

```sh
npx serve game
# then open http://localhost:3000 in desktop Chrome
# or: python3 -m http.server --directory game 8080
```
